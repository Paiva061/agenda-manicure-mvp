# Agenda Manicure - MVP

MVP para organizar a agenda de uma manicure autônoma em Sobradinho, DF.

## Problema
Perda de clientes por marcações duplicadas, esquecimentos e controle no WhatsApp e no papel.

## Funcionalidades do MVP
- Ver agenda do dia
- Criar agendamento (cliente, serviço, data, hora)
- Cadastrar cliente
- Alerta de horário já ocupado
- Confirmação "Cliente salva."

## Tecnologias
Protótipo em telas de celular. Código do MVP será versionado aqui.

## Como testar
1. Abrir a Agenda do dia
2. Clicar em Agendar
3. Preencher cliente, serviço, data e hora
4. Clicar em Salvar
